# 学工办助理排班成员端小程序

这是 `v7.0` 的成员端微信小程序版本，管理员后台仍使用现有网页。

## 当前已包含

- 姓名 + 密码登录，复用现有成员账号
- 查看今日班次与签到状态
- 签到 / 签退，复用网页端同一套定位与时间窗口规则
- 查看当前周期我的班次
- 发起换班 / 代班申请
- 同意、拒绝、撤回换班 / 代班申请
- 维护个人信息与邮箱
- 保存微信订阅提醒偏好

## 与网页端的数据关系

小程序直接访问现有后端：

```text
https://shift-scheduler-93l6.onrender.com/api
```

网页端和小程序端共用同一个 MongoDB 数据源。网页端完成签到、签退、换班、代班后，小程序下拉刷新即可看到最新状态。

## 本地预览

1. 打开微信开发者工具
2. 选择“导入项目”
3. 目录选择本文件夹：`miniprogram-member`
4. AppID 先填测试号或正式小程序 AppID
5. 编译运行

## 正式上线前需要配置

1. 在微信公众平台小程序后台配置 request 合法域名：

```text
https://shift-scheduler-93l6.onrender.com
```

2. 在小程序后台申请订阅消息模板。
3. 把模板 ID 填入 `app.js` 的 `subscribeTemplateIds`。
4. 在 Render 配置小程序登录环境变量：

```text
WECHAT_MINI_APPID=你的小程序 AppID
WECHAT_MINI_SECRET=你的小程序 AppSecret
```

5. 成员登录小程序后，后端会尝试绑定该成员的 `openid`，用于后续发送订阅消息。

## 暂未包含

- 管理员后台小程序版
- 自动定时发送微信订阅消息
- 复杂候补管理

这些可以在成员端跑通后继续加，不影响现有网页系统。
